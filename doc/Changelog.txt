 - Hotkeys enabled
   '<ctrl><shift>P' : Start playing current song
   '<ctrl><shift>S' : Stop playing
   '<ctrl><shift>N' : Next song
   '<ctrl><shift>B' : Previouse song (B = BACK)
   '<ctrl><shift>D' : Show/Hide player (D = DISPLAY)
   '<ctrl><shift>W' : Pause/unpause song (W = WAIT)
